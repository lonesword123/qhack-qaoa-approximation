# QHack QAOA approximation

This repository contains my solution to a QHack challenge that applies the **Quantum Approximate Optimization Algorithm (QAOA)** to the **Minimum Vertex Cover** problem.

The implementation builds the problem Hamiltonians for an arbitrary graph, runs a four-layer QAOA circuit in PennyLane, optimizes the circuit parameters with gradient descent, and compares the resulting expectation value with the exact minimum eigenvalue of the cost Hamiltonian.

## Problem statement

For a graph \(G=(V,E)\), a vertex cover is a subset of vertices \(C \subseteq V\) such that every edge has at least one endpoint in \(C\). The Minimum Vertex Cover problem asks for a vertex cover with the smallest possible number of vertices.

For example, if an edge connects vertices `i` and `j`, then at least one of `i` or `j` must be selected. The challenge encodes these constraints as a cost Hamiltonian and uses QAOA to search for a low-cost computational-basis state.

The QHack task required:

1. Constructing the cost and mixer Hamiltonians.
2. Implementing a QAOA circuit.
3. Using exactly four QAOA layers.
4. Optimizing the QAOA parameters.
5. Comparing the QAOA estimate with the exact classical minimum eigenvalue.

## QAOA formulation

The challenge provides the following cost Hamiltonian:

\[
H_{cost} = \frac{3}{4}\sum_{(i,j)\in E}(Z_iZ_j + Z_i + Z_j) - \sum_{i\in V} Z_i.
\]

The mixer Hamiltonian is:

\[
H_{mixer} = \sum_{i\in V} X_i.
\]

Here, \(Z_i\) and \(X_i\) are Pauli-Z and Pauli-X operators acting on the qubit associated with vertex \(i\).

For each edge, the implementation adds a coefficient of `0.75` to the \(Z_iZ_j\) term. It also counts the degree of every vertex and adds the corresponding linear coefficient:

```text
0.75 * degree(vertex) - 1.0
```

This is equivalent to collecting the individual \(Z_i\) and \(Z_j\) terms from the edge sum.

The QAOA circuit starts in an equal superposition by applying Hadamard gates to every qubit. Each of the four layers then applies:

1. A cost unitary generated by `H_cost`.
2. A mixer unitary generated by `H_mixer`.

The two parameter vectors contain four cost angles and four mixer angles:

```text
params[0] = [gamma_1, gamma_2, gamma_3, gamma_4]
params[1] = [alpha_1, alpha_2, alpha_3, alpha_4]
```

## Implementation

The main implementation is in [`solution.py`](solution.py).

### `build_hamiltonians(edges)`

This helper function:

- Extracts and sorts the graph vertices.
- Counts the degree of every vertex.
- Builds the Pauli-Z interaction terms for every edge.
- Builds the single-qubit Pauli-Z terms from the vertex degrees.
- Builds the mixer from Pauli-X operators.

It returns the vertex list, the cost Hamiltonian, and the mixer Hamiltonian.

### `approximation_ratio(edges)`

This function:

- Creates a PennyLane `default.qubit` simulator with one wire per graph vertex.
- Defines a four-layer QAOA circuit.
- Initializes all QAOA parameters to `0.5`.
- Performs 300 gradient-descent optimization steps.
- Evaluates the optimized cost expectation value.
- Computes the exact minimum eigenvalue using `qp.eigvals`.
- Returns the ratio of the QAOA estimate to the exact value.

### Challenge-compatible helpers

The `run` and `check` functions preserve the JSON input/output format used by the challenge. When `solution.py` is run directly, it executes the two public test cases and prints whether each result passes the checker.

## Installation

Clone the repository and enter its directory:

```bash
git clone https://github.com/lonesword123/qhack-qaoa-approximation.git
cd qhack-qaoa-approximation
```

Create a virtual environment and install the dependency:

```bash
python -m venv .venv
```

Activate it on macOS/Linux:

```bash
source .venv/bin/activate
```

Activate it in Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install PennyLane:

```bash
pip install -r requirements.txt
```

## Running the solution

Run the built-in public tests:

```bash
python solution.py
```

The program prints a line for each test case and reports `Correct!` when the result is within the challenge tolerance.

To use the function from another Python file:

```python
from solution import approximation_ratio

edges = [[0, 1], [1, 2], [0, 2], [2, 3]]
ratio = approximation_ratio(edges)
print(ratio)
```

The edge list should contain pairs of integer vertex labels. The current implementation assumes that the vertex labels can be used directly as PennyLane wire labels.

## How the approximation ratio is computed

After optimization, the code obtains:

- `qaoa_min`: the expectation value estimated by the optimized QAOA circuit.
- `true_min`: the exact minimum eigenvalue of the cost Hamiltonian, computed classically.

It returns:

\[
r = \frac{\text{QAOA minimum expectation value}}{\text{exact minimum eigenvalue}}.
\]

The exact eigenvalue calculation is practical for the small graphs used in the challenge, but it scales exponentially with the number of qubits and is included for comparison rather than as a scalable solver.

## Limitations and reproducibility

- The QAOA optimization uses a local gradient-descent optimizer and a fixed initial parameter array; it is not guaranteed to find a globally optimal parameter set.
- Runtime and numerical results can vary with PennyLane and simulator versions.
- The exact eigenvalue calculation becomes expensive as the graph grows.
- The current implementation expects integer vertex labels suitable for direct use as qubit wires.
- The public results are recorded from the original challenge run and should be interpreted with the stated tolerance.

## Background

This project was developed as a solution to a QHack quantum-computing challenge. It is intended as a compact example of translating a graph optimization problem into Hamiltonians and evaluating a QAOA ansatz with PennyLane.
